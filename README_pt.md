# Como Usar GPT Image 2.5 para E-commerce

> Um livro de receitas de prompts para criar imagens de e-commerce com **GPT Image 2.5** — fotos de listagem, prova de roupa em modelo, showcases de produto, cenas de interação e criativos de social commerce.

## 🍌 Introdução

Este repositório te mostra **como usar GPT Image 2.5 para criar imagens de e-commerce** — fotos de listagem, imagens principais multi-país, visuais de detalhe A+, prova em modelo, showcases de produto, cenas de interação e criativos de social commerce — em escala de produção.

**Cada caso é uma receita:** uma foto do produto de entrada, o prompt exato para colar no GPT Image 2.5 e exemplos reais de saída. Substitua os `{placeholders}` pelo seu produto, idioma, país e pontos de venda.

Se for útil, deixe uma Star ⭐

> [!NOTE]
> Este repositório se concentra em templates de prompt reutilizáveis para criativos de e-commerce. Substitua os placeholders entre chaves antes do uso e ajuste para sua plataforma, mercado, idioma, produto, material, tipo de modelo e pontos de venda reais.

## Como usar estes prompts

1. **Escolha um caso** abaixo que corresponda ao seu objetivo de e-commerce (imagem principal, prova em modelo, produto multi-ângulo, visuais A+, etc.).
2. **Faça upload da foto do seu produto** e **copie o prompt** do caso — substitua os `{placeholders}` pelo seu produto, idioma, país, plataforma e pontos de venda.
3. **Execute no GPT Image 2.5** — seja pela [UI do workflow Evolink](https://evolink.ai/gpt-image-2-5-sunburst?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce) para criativos pontuais, ou via [API Evolink](#-geração-em-lote-via-api-evolink) para SKUs em massa e rollouts multilíngues.

```text
Edit the supplied real product photograph. Replace only the surrounding scene with {scene_description}. Keep the product itself unchanged: preserve its exact shape, proportions, yellow packaging, cap, logo, label text, material and visible details. Match the new background lighting and contact shadows naturally. Do not redesign, relabel, duplicate or obscure the product.
```

### Caso 32: Divulgação de produtos no estilo UGC

Criar demonstrações no estilo de criadores e um painel de campanha UGC para vários mercados a partir da referência do produto.

**Prompt reutilizável**

```text
Using the supplied white-background product photo as the product reference, create a UGC-style skincare promotion image for {target_market}. Show an adult creator naturally holding the same product in a believable everyday setting. Preserve the exact product packaging, color, proportions, logo and label. Use a casual phone-camera composition and natural lighting. If text is needed, use only {approved_copy} in {language}. Do not invent testimonials, certifications or product benefits.
```

## 🚀 Geração em Lote via API Evolink

Os exemplos de API usam GPT Image 2.5 Flare. Para edições precisas, escolha GPT Image 2.5 Sunburst com os mesmos campos documentados.

Use várias solicitações para um catálogo; n define a quantidade de imagens por solicitação.

[Documentação da API GPT Image 2.5](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

Para execuções de produção em centenas de SKUs, vários idiomas ou vários marketplaces, chame diretamente a **API GPT Image 2.5 da Evolink** em vez de rodar prompts um a um.

**Por que processar em lote via API:**

- Geração em massa de imagens de listagem para um catálogo inteiro
- Tradução multilíngue de todos os ativos de listagem em uma única tarefa
- Troca de modelo, substituição de fundo e saída multi-ângulo programáticas
- Callbacks webhook integram com seu PIM, ERP ou automação de marketing

**Pré-requisitos:** [Obtenha uma chave API](https://evolink.ai/dashboard/keys).

### Passo 1: Enviar uma tarefa de geração

A geração GPT Image 2.5 é **assíncrona** — a chamada retorna um `id` que você consulta para obter os resultados.

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| Campo | Obrigatório | Notas |
| :--- | :--- | :--- |
| `model` | sim | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | sim | Até 32.000 caracteres — cole o prompt de qualquer caso deste repo |
| `image_urls` | opcional | 1–16 imagens de entrada/referência (jpeg/png/webp, ≤50 MB cada) para tarefas image-to-image e edição |
| `size` | opcional | Proporção (`1:1`, `2:3`, `16:9`, …) ou dimensões em pixels; padrão `auto` |
| `resolution` | opcional | `1K`, `2K` ou `4K` quando `size` é uma proporção |
| `quality` | opcional | `low`, `medium`, `high`, `xhigh`, `max` — afeta o custo; padrão `medium` |
| `n` | opcional | 1–10 imagens por chamada |
| `callback_url` | opcional | Webhook HTTPS para receber conclusão em vez de polling |

### Passo 2: Consultar a tarefa

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Quando `status` se torna `"completed"`, o array `results` contém as URLs das imagens geradas. **Imagens geradas são válidas por 24 horas — baixe-as prontamente.**

### Opcional: callback webhook

Passe `"callback_url": "https://your-server.example.com/webhook"` no envio e a Evolink fará POST do resultado para seu endpoint quando a tarefa concluir — sem polling.
