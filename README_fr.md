# Comment Utiliser GPT Image 2.5 pour l'E-commerce

> Un recueil de prompts pour créer des images e-commerce avec **GPT Image 2.5** — photos de fiches produit, essayage virtuel, présentations produit, scènes d'interaction et créations social commerce.

## 🍌 Introduction

Ce dépôt vous montre **comment utiliser GPT Image 2.5 pour créer des images e-commerce** — photos de fiches produit, images principales multi-pays, visuels de détail A+, essayage virtuel, présentations produit, scènes d'interaction et créations social commerce — à l'échelle de la production.

**Chaque cas est une recette :** une photo produit en entrée, le prompt exact à coller dans GPT Image 2.5 et de vrais exemples de sortie. Remplacez les `{placeholders}` par votre produit, langue, pays et arguments de vente.

Si vous le trouvez utile, donnez-nous une Star ⭐

> [!NOTE]
> Ce dépôt se concentre sur des modèles de prompts réutilisables pour les créations e-commerce. Remplacez les placeholders entre accolades avant utilisation et adaptez-les à votre plateforme, marché, langue, produit, matériau, type de mannequin et arguments de vente réels.

## Comment utiliser ces prompts

1. **Choisissez un cas** ci-dessous correspondant à votre objectif e-commerce (image principale, essayage modèle, produit multi-angles, visuels A+, etc.).
2. **Téléchargez la photo de votre produit** et **copiez le prompt** de ce cas — remplacez les `{placeholders}` par votre produit, langue, pays, plateforme et arguments de vente.
3. **Exécutez sur GPT Image 2.5** — soit via l'[interface du workflow Evolink](https://evolink.ai/gpt-image-2-5-sunburst?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce) pour les créations ponctuelles, soit via l'[API Evolink](#-génération-par-lots-via-lapi-evolink) pour les SKU en masse et les déploiements multilingues.

### Cas 31: Changer le décor, conserver le produit

Remplacer l’environnement du produit photographié tout en conservant sa forme, son emballage et son étiquette.

**Prompt réutilisable**

```text
Edit the supplied real product photograph. Replace only the surrounding scene with {scene_description}. Keep the product itself unchanged: preserve its exact shape, proportions, yellow packaging, cap, logo, label text, material and visible details. Match the new background lighting and contact shadows naturally. Do not redesign, relabel, duplicate or obscure the product.
```

### Cas 32: Promotion produit au style UGC

Créer des démonstrations au style créateur et une planche de campagne UGC pour plusieurs marchés à partir de la référence produit.

**Prompt réutilisable**

```text
Using the supplied white-background product photo as the product reference, create a UGC-style skincare promotion image for {target_market}. Show an adult creator naturally holding the same product in a believable everyday setting. Preserve the exact product packaging, color, proportions, logo and label. Use a casual phone-camera composition and natural lighting. If text is needed, use only {approved_copy} in {language}. Do not invent testimonials, certifications or product benefits.
```

### Cas 5 : Remplacement en Masse de l'Image Principale

**Entrée :** Téléchargez l'image du produit source et le set d'images de fiche cible.

**Prompt :**

```
Replace the product in image 1 across images 2–7. Only the swapped product changes; keep everything else identical.
```

> [!NOTE]
> Recréation en un coup d'une fiche virale — échangez le produit sans redesigner la mise en page. Utile lorsque plusieurs SKU réutilisent le même style créatif.

## 🚀 Génération par Lots via l'API Evolink

Les exemples API utilisent GPT Image 2.5 Flare. Pour des retouches précises, choisissez GPT Image 2.5 Sunburst avec les mêmes champs documentés.

Traitez un catalogue avec plusieurs requêtes ; n indique le nombre d’images par requête.

[Documentation API GPT Image 2.5](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

Pour les exécutions en production sur des centaines de SKU, plusieurs langues ou plusieurs marketplaces, appelez directement l'**API Evolink GPT Image 2.5** au lieu d'exécuter les prompts un par un.

**Pourquoi le batch via API :**

- Génération en masse d'images de fiches pour un catalogue entier
- Traduction multilingue de tous les actifs de fiche en une seule tâche
- Changement de modèle, remplacement de fond et sortie multi-angles programmatiques
- Callbacks webhook s'intègrent avec votre PIM, ERP ou automatisation marketing

**Prérequis :** [Obtenez une clé API](https://evolink.ai/dashboard/keys).

### Étape 1 : Soumettre une tâche de génération

La génération GPT Image 2.5 est **asynchrone** — l'appel renvoie un `id` que vous interrogez pour obtenir les résultats.

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| Champ | Requis | Notes |
| :--- | :--- | :--- |
| `model` | oui | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | oui | Jusqu'à 32 000 caractères — collez le prompt de n'importe quel cas de ce dépôt |
| `image_urls` | optionnel | 1–16 images d'entrée/référence (jpeg/png/webp, ≤50 Mo chacune) pour les tâches image-to-image et édition |
| `size` | optionnel | Ratio d'aspect (`1:1`, `2:3`, `16:9`, …) ou dimensions en pixels ; par défaut `auto` |
| `resolution` | optionnel | `1K`, `2K` ou `4K` quand `size` est un ratio |
| `quality` | optionnel | `low`, `medium`, `high`, `xhigh`, `max` — affecte le coût ; par défaut `medium` |
| `n` | optionnel | 1–10 images par appel |
| `callback_url` | optionnel | Webhook HTTPS pour recevoir le résultat au lieu du polling |

### Étape 2 : Interroger la tâche

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Lorsque `status` devient `"completed"`, le tableau `results` contient les URLs des images générées. **Les images générées sont valides 24 heures — téléchargez-les rapidement.**

### Optionnel : callback webhook

Passez `"callback_url": "https://your-server.example.com/webhook"` dans la soumission et Evolink fera un POST du résultat à votre endpoint à la fin de la tâche — pas de polling.
