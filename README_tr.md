## 🍌 Tanıtım

Bu depo size **GPT Image 2.5 ile e-ticaret görsellerini nasıl oluşturacağınızı** gösterir — liste fotoğrafları, çok ülkeli ana görseller, A+ detay görselleri, model prova, ürün vitrinleri, etkileşim sahneleri ve social commerce kreatiflerini üretim ölçeğinde.

Match the new background lighting and contact shadows naturally. Do not redesign, relabel, duplicate or obscure the product.

**Yeniden kullanılabilir istem**

```text
Using the supplied white-background product photo as the product reference, create a UGC-style skincare promotion image for {target_market}. Show an adult creator naturally holding the same product in a believable everyday setting. Preserve the exact product packaging, color, proportions, logo and label. Use a casual phone-camera composition and natural lighting. If text is needed, use only {approved_copy} in {language}. Do not invent testimonials, certifications or product benefits.
```

## 🚀 Evolink API ile Toplu Üretim

API örnekleri GPT Image 2.5 Flare kullanır. Hassas düzenleme için aynı belgelenmiş istek alanlarına sahip GPT Image 2.5 Sunburst seçilebilir.

Bir katalog için birden fazla istek kullanın; n, her istekte üretilecek görsel sayısını belirler.

[GPT Image 2.5 API belgeleri](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

Yüzlerce SKU, birden fazla dil veya birden fazla marketplace üzerindeki üretim koşuları için promptları tek tek çalıştırmak yerine doğrudan **Evolink GPT Image 2.5 API'sini** çağırın.

**Neden API ile toplu işlem:**

- Tüm katalog için toplu liste görseli üretimi
- Tüm liste varlıklarının çok dilli çevirisi tek bir görevde
- Programatik model değişimi, arka plan değiştirme, çok açılı çıktı
- Webhook callback'leri PIM, ERP veya pazarlama otomasyonunuzla entegre olur

**Ön koşullar:** [API anahtarı alın](https://evolink.ai/dashboard/keys).

### Adım 1: Üretim görevi gönderme

GPT Image 2.5 üretimi **asenkrondur** — çağrı bir `id` döndürür ve sonuçları sorgulayarak alırsınız.

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| Alan | Zorunlu | Notlar |
| :--- | :--- | :--- |
| `model` | evet | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | evet | 32.000 karaktere kadar — bu repo'daki herhangi bir vakanın promptunu yapıştırın |
| `image_urls` | opsiyonel | image-to-image ve düzenleme görevleri için 1–16 giriş/referans görsel (jpeg/png/webp, her biri ≤50 MB) |
| `size` | opsiyonel | En-boy oranı (`1:1`, `2:3`, `16:9`, …) veya piksel boyutu; varsayılan `auto` |
| `resolution` | opsiyonel | `size` bir oran ise `1K`, `2K` veya `4K` |
| `quality` | opsiyonel | `low`, `medium`, `high`, `xhigh`, `max` — maliyeti etkiler; varsayılan `medium` |
| `n` | opsiyonel | Çağrı başına 1–10 görsel |
| `callback_url` | opsiyonel | Polling yerine tamamlanma bildirimi alacak HTTPS webhook |

### Adım 2: Görevi sorgulama

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

`status` `"completed"` olduğunda, `results` dizisi üretilen görsel URL'lerini içerir. **Üretilen görseller 24 saat geçerlidir — gecikmeden indirin.**

### Opsiyonel: webhook callback

Gönderimde `"callback_url": "https://your-server.example.com/webhook"` geçirin; görev tamamlandığında Evolink sonucu endpoint'inize POST eder — polling gerekmez.

**Tam API referansı:** [docs.evolink.ai · GPT Image 2.5 görsel üretimi](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation)
