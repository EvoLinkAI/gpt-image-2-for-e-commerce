## 🍌 簡介

本倉庫教你**如何使用 GPT Image 2.5 製作電商素材**——電商主圖、多國本地化套圖、A+ 產品詳情、模特試穿、產品多角度展示、互動場景、社交電商帶貨圖——並支援規模化生產

**每個案例都是一份配方：** 一張產品原圖 + 直接複製即用的 GPT Image 2.5 提示詞 + 真實輸出示例。使用前把 `{佔位符}` 替換為你自己的商品、語言、國家和賣點即可

如果覺得有用，歡迎點個 Star ⭐

> [!NOTE]
> 本倉庫專注於可複用的電商素材提示詞模板。使用前請替換大括號中的佔位符，並根據實際的平臺、市場、語言、產品、材質、模特型別和賣點進行調整

## 🚀 批次生成 · 呼叫 Evolink API

API 範例使用 GPT Image 2.5 Flare；精細編輯可選 GPT Image 2.5 Sunburst，兩者使用文件列出的相同請求欄位

商品目錄使用多次請求處理，n 表示單次請求生成的圖片數

[GPT Image 2.5 API 文件](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

如果你需要在大量 SKU、多語言、多平臺之間規模化生產電商素材，建議直接呼叫 **Evolink GPT Image 2.5 API**，而不是逐張手動生成

**為什麼用 API 跑批次：**

- 整盤 SKU 的電商主圖一次性出圖
- 一次任務搞定全部主圖的多語言版本翻譯
- 程式化模特替換、背景替換、多角度出圖
- Webhook 回撥可直接對接 PIM、ERP 或營銷自動化系統

**前置條件：** [獲取 API Key](https://evolink.ai/dashboard/keys)

### 步驟 1：提交生成任務

GPT Image 2.5 是**非同步任務**——介面返回 `id`，需要輪詢任務詳情拿到結果

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| 欄位 | 是否必填 | 說明 |
| :--- | :--- | :--- |
| `model` | 必填 | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | 必填 | 最長 32,000 字元——直接複製本倉庫任意 case 的提示詞即可 |
| `image_urls` | 可選 | 1–16 張參考圖（jpeg/png/webp，單張 ≤50 MB），用於圖生圖與編輯場景 |
| `size` | 可選 | 比例（`1:1`、`2:3`、`16:9` …）或畫素尺寸；預設 `auto` |
| `resolution` | 可選 | `1K`、`2K`、`4K`，配合比例使用 |
| `quality` | 可選 | `low` / `medium` / `high` / `xhigh` / `max`，影響計費；預設 `medium` |
| `n` | 可選 | 單次生成 1–10 張 |
| `callback_url` | 可選 | HTTPS Webhook 地址，任務完成後回撥，無需輪詢 |

### 步驟 2：輪詢任務結果

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

當 `status` 變為 `"completed"` 時，`results` 數組裡就是生成的圖片 URL。**生成的圖片僅 24 小時內有效，請儘快下載留存。**

### 可選：Webhook 回撥

在提交任務時傳入 `"callback_url": "https://your-server.example.com/webhook"`，Evolink 會在任務完成後 POST 結果到你指定的介面，無需輪詢

**完整 API 文件：** [docs.evolink.ai · GPT Image 2.5 image generation](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation)
