# How to Use GPT Image 2.5 for E-commerce

> A prompt cookbook for creating e-commerce images with **GPT Image 2.5** — listing photos, model try-on, product showcases, interaction scenes, and social commerce creatives.

## 🍌 Introduction

This repository shows you **how to use GPT Image 2.5 to create e-commerce images** — listing photos, multi-country main images, A+ detail visuals, model try-on, product showcases, interaction scenes, and social commerce creatives — at production scale.

**Every case below is a recipe:** an input product photo, the exact prompt to paste into GPT Image 2.5, and real output examples. Replace the `{placeholders}` with your product, language, country, and selling points.

If you find it useful, please give us a Star ⭐

> [!NOTE]
> This repository focuses on reusable prompt templates for ecommerce creatives. Replace the placeholders inside curly braces before use, and adjust to fit your actual platform, market, language, product, material, model type, and selling points.

## How to Use These Prompts

1. **Pick a case** below that matches your e-commerce goal (listing main image, model try-on, multi-angle product, A+ detail visuals, etc.).
2. **Upload your product photo** and **copy the prompt** from that case — replace `{placeholders}` with your product, language, country, platform, and selling points.
3. **Run it on GPT Image 2.5** — either through the [Evolink workflow UI](https://evolink.ai/gpt-image-2-5-sunburst?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce) for one-off creatives, or via the [Evolink API](#-batch-generation-via-evolink-api) for bulk SKUs and multi-language rollouts.

## 🚀 Batch Generation via Evolink API

API examples use GPT Image 2.5 Flare. For precision editing, choose GPT Image 2.5 Sunburst with the same documented request fields.

Use repeated requests for a catalog; n controls the images returned by one request.

[GPT Image 2.5 API documentation](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

For production runs across hundreds of SKUs, multiple languages, or multiple marketplaces, call the **Evolink GPT Image 2.5 API** directly instead of running prompts one by one.

**Why batch via API:**

- Bulk listing image generation for an entire catalog
- Multilingual translation of all listing assets in a single job
- Programmatic model swap, background replacement, multi-angle output
- Webhook callbacks integrate with your PIM, ERP, or marketing automation

**Prerequisites:** [Get an API key](https://evolink.ai/dashboard/keys).

### Step 1: Submit a generation task

GPT Image 2.5 generation is **asynchronous** — the call returns a `id` that you poll for results.

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| Field | Required | Notes |
| :--- | :--- | :--- |
| `model` | yes | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | yes | Up to 32,000 characters — paste the prompt from any case in this repo |
| `image_urls` | optional | 1–16 input/reference images (jpeg/png/webp, ≤50 MB each) for image-to-image and editing tasks |
| `size` | optional | Aspect ratio (`1:1`, `2:3`, `16:9`, …) or pixel dimensions; defaults to `auto` |
| `resolution` | optional | `1K`, `2K`, or `4K` when `size` is a ratio |
| `quality` | optional | `low`, `medium`, `high`, `xhigh`, `max` — affects cost; defaults to `medium` |
| `n` | optional | 1–10 images per call |
| `callback_url` | optional | HTTPS webhook to receive completion instead of polling |

### Step 2: Poll the task

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

When `status` becomes `"completed"`, the `results` array contains the generated image URLs. **Generated images are valid for 24 hours — download them promptly.**

### Optional: webhook callback

Pass `"callback_url": "https://your-server.example.com/webhook"` in the submission, and Evolink will POST the task result to your endpoint when the task completes — no polling required.

**Full API reference:** [docs.evolink.ai · GPT Image 2.5 image generation](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation)
