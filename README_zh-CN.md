# 如何使用 GPT Image 2.5 制作电商素材

> 一份面向 **GPT Image 2.5** 的电商素材制作提示词手册——涵盖主图套图、多国主图、模特试穿、产品展示、互动场景、社交电商等场景

## 🍌 简介

本仓库教你**如何使用 GPT Image 2.5 制作电商素材**——电商主图、多国本地化套图、A+ 产品详情、模特试穿、产品多角度展示、互动场景、社交电商带货图——并支持规模化生产

**每个案例都是一份配方：** 一张产品原图 + 直接复制即用的 GPT Image 2.5 提示词 + 真实输出示例。使用前把 `{占位符}` 替换为你自己的商品、语言、国家和卖点即可

如果觉得有用，欢迎点个 Star ⭐

> [!NOTE]
> 本仓库专注于可复用的电商素材提示词模板。使用前请替换大括号中的占位符，并根据实际的平台、市场、语言、产品、材质、模特类型和卖点进行调整

## 如何使用这些提示词

1. **挑一个案例**——找到与你目标最匹配的电商场景（主图、模特试穿、产品多角度、A+ 详情等）
2. **上传产品原图、复制提示词**——把案例下方的提示词复制走，把 `{占位符}` 替换为你的商品、语言、国家、平台和卖点
3. **在 GPT Image 2.5 上跑起来**——单图出货可走 [Evolink 工作流 UI](https://evolink.ai/gpt-image-2-5-sunburst?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)；多 SKU、多语言批量生产请走 [Evolink API](#-批量生成--调用-evolink-api)

## 🚀 批量生成 · 调用 Evolink API

API 示例使用 GPT Image 2.5 Flare；精细编辑可选 GPT Image 2.5 Sunburst，两者使用文档列出的相同请求字段

商品目录使用多次请求处理，n 表示单次请求生成的图片数

[GPT Image 2.5 API 文档](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation?utm_source=github&utm_medium=readme&utm_campaign=gpt-image-2-for-e-commerce)

如果你需要在大量 SKU、多语言、多平台之间规模化生产电商素材，建议直接调用 **Evolink GPT Image 2.5 API**，而不是逐张手动生成

**为什么用 API 跑批量：**

- 整盘 SKU 的电商主图一次性出图
- 一次任务搞定全部主图的多语言版本翻译
- 程序化模特替换、背景替换、多角度出图
- Webhook 回调可直接对接 PIM、ERP 或营销自动化系统

**前置条件：** [获取 API Key](https://evolink.ai/dashboard/keys)

### 步骤 1：提交生成任务

GPT Image 2.5 是**异步任务**——接口返回 `id`，需要轮询任务详情拿到结果

```bash
curl -X POST https://api.evolink.ai/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "Create one premium e-commerce product image using the supplied yellow skincare product. Keep its packaging, color, proportions, logo and label unchanged. Place it in a naturally lit bathroom scene.",
    "image_urls": ["https://pub-62cf7640cd0f4066b60933bd2e9b85ef.r2.dev/github-repo-media/gpt-image-2-for-e-commerce/.codex/gpt-image-2.5-migration/media/3f93f078be25efbc86b244fccd38cb771601cce6e2af182252bd0ce2df35739b.png"],
    "size": "1:1",
    "resolution": "1K",
    "quality": "low",
    "n": 1
  }'
```

| 字段 | 是否必填 | 说明 |
| :--- | :--- | :--- |
| `model` | 必填 | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` |
| `prompt` | 必填 | 最长 32,000 字符——直接复制本仓库任意 case 的提示词即可 |
| `image_urls` | 可选 | 1–16 张参考图（jpeg/png/webp，单张 ≤50 MB），用于图生图与编辑场景 |
| `size` | 可选 | 比例（`1:1`、`2:3`、`16:9` …）或像素尺寸；默认 `auto` |
| `resolution` | 可选 | `1K`、`2K`、`4K`，配合比例使用 |
| `quality` | 可选 | `low` / `medium` / `high` / `xhigh` / `max`，影响计费；默认 `medium` |
| `n` | 可选 | 单次生成 1–10 张 |
| `callback_url` | 可选 | HTTPS Webhook 地址，任务完成后回调，无需轮询 |

### 步骤 2：轮询任务结果

```bash
curl https://api.evolink.ai/v1/tasks/{id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

当 `status` 变为 `"completed"` 时，`results` 数组里就是生成的图片 URL。**生成的图片仅 24 小时内有效，请尽快下载留存。**

### 可选：Webhook 回调

在提交任务时传入 `"callback_url": "https://your-server.example.com/webhook"`，Evolink 会在任务完成后 POST 结果到你指定的接口，无需轮询

**完整 API 文档：** [docs.evolink.ai · GPT Image 2.5 image generation](https://evolink.ai/docs/en/api-manual/image-series/gpt-image-2.5/gpt-image-2.5-image-generation)
